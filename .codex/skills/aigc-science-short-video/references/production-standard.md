# Production Standard Reference

## Reference bundle decision

| Segment situation | Minimum input | Do not add unless needed |
| --- | --- | --- |
| Same scene, same camera position | Prior same-position screenshot + prior audio | Separate character, scene, voice assets |
| Reverse angle | Character asset + key reverse-angle storyboard image + prior audio | Conflicting scene/frame references |
| New scene or prop | Approved scene/prop asset + key storyboard image | A dense multi-grid board |
| New character appearance | Approved 3:4 character asset | Another unapproved character reference |
| Continuing dialogue | Prior audio + approved voice reference only if audio is insufficient | Duplicate voice/style references |

## Storyboard and audio checks

- Use one action or one line of emphasis per shot. Split a change of focus, action, or camera language into another shot.
- Allocate more shots to the key science explanation than to setup or ending. Use fast, varied, motivated camera language.
- Keep dialogue in the visual description; list only BGM, ambience, and necessary effects in the audio field.
- Name a BGM bed once, then reuse its exact description across its continuous coverage. Use fades and J/L cuts at boundaries.

## Final QC

- [ ] Scene changes are foreshadowed with sound, action, or visual transition.
- [ ] Character face, silhouette, clothes, voice, and tone remain stable.
- [ ] No low-quality image was used as an iterative reference without upscaling.
- [ ] No visible prop, hand, perspective, or spatial continuity error remains.
- [ ] BGM covers at least half the video and loudness feels consistent.
- [ ] Major scene changes dissolve; memory/thought-travel material uses an intentional grade.
- [ ] Master is upscaled before subtitles; final file and approvals are recorded.
