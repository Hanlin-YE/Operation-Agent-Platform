我会按“最小改动、复用现有样式”的方式实现：

1. 调整首页导航结构（`src/components/layout/OperationsShell.tsx`）
   - 首页不再展开显示二级项“运营总览”。
   - 侧边栏里“首页”本身直接作为可点击入口，点击后进入 `/`。
   - 顶部面包屑同步改为只显示“首页”，避免继续出现 `首页 / 运营总览`。
   - 其他导航分组保持现有二级菜单结构不变。

2. 调整首页“自媒体创作”卡片文案与结构（`src/app/page.tsx`）
   - 删除标题文字“下一条值得做的内容”。
   - 将该卡片明确拆成两个板块：
     - `推荐选题`：保留现有基于 P0 市场推荐的选题内容。
     - `灵感自述`：改为用户手动录入灵感的区域。
   - 把原来的“自述灵感 / 新建”链接改为“灵感自述 / 录入灵感”的交互入口。

3. 新增一个首页客户端组件用于灵感记事本功能
   - 新建类似 `src/components/home/HomeInspirationNotebook.tsx` 的 client component。
   - 使用 React state 管理弹窗开关、表单输入、灵感列表。
   - 使用 `localStorage` 持久化灵感列表，这样刷新页面后仍能看到本机录入内容；不新增后端接口，避免扩大改动范围。
   - 点击“录入灵感”打开弹窗。
   - 弹窗包含：
     - 文本框：`灵感标题`，必填。
     - 文本框：`备注`，可为空。
     - 按钮：`取消`、`保存`。
   - 保存后关闭弹窗，并把灵感展示在首页卡片中，样式做成 todolist / checklist 形式。
   - 可附带一个“已记录”视觉标记；不实现删除/编辑，除非后续你需要。

4. 补充样式（`src/app/globals.css`）
   - 在现有首页 `.plan-highlight`、`.idea-entry` 样式附近新增/调整样式。
   - 复用已有弹窗风格（参考 `knowledge-settings-overlay/dialog`），新增更轻量的灵感弹窗样式。
   - 新增灵感 todolist 的空状态、列表项、标题/备注展示、按钮样式。
   - 尽量保持现有深色运营工作台视觉一致。

5. 验证
   - 运行项目已有的检查命令（优先查看 `package.json` 后执行合适的 lint/typecheck/build 命令）。
   - 检查首页导航、首页卡片、弹窗表单必填校验、保存后展示、刷新后 localStorage 恢复。
