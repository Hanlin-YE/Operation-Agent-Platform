## 当前业务判断

结合官网，清力/FrictionX 的拓客不应泛泛围绕“超滑材料”，而应围绕四类具象场景：

```text
通信射频：MEMS射频开关、5G/5.5G/6G基站、相控阵雷达、ATE
微能量采集：微动发电机、物联网传感器、智慧电网/物流/铁路/工厂
精密微电机：空心杯有刷电机、人形机器人、医疗器械、无人机、航天航空
微纳制造平台：光刻、镀膜、刻蚀、键合、抛光、封装、器件测试
```

超滑项目的拓客策略应围绕这些共性痛点展开：

```text
降低摩擦损耗
提升寿命和可靠性
降低发热
提升高频/高速/高精密设备稳定性
减少维护成本
增强材料表面性能
```

## 拓客主线一：微动发电机 / 能量采集

### 客户画像

优先找：

- 物联网传感器企业
- 智慧电网传感终端企业
- 铁路、物流、工厂设备状态监测企业
- 低功耗无线传感器企业
- 微能量采集模块企业
- 工业预测性维护方案商

### 超滑切入点

- 微小振动能量采集效率
- 无源/少维护传感节点供电
- 微动结构长期可靠性
- 低频、低幅振动下的能量转化
- 工业现场电池更换维护成本

### 销售话术方向

不要上来讲“材料很先进”，要讲：

- “能否减少传感节点更换电池”
- “能否利用设备运行振动进行自供电”
- “能否提升微动发电结构长期稳定性”
- “能否服务智慧电网、物流、铁路和工厂的低功耗终端”

- 微型电机企业
- 空心杯电机企业
- 伺服执行器企业
- 医疗器械、无人机、航天航空微驱动企业

### 超滑切入点

- 空心杯有刷电机电刷/换向器磨损
- 微型电机寿命和噪声

- “高频动作下磨损和噪声能不能下降”
- “能不能降低维护频率”
- “是否适合灵巧手、医疗器械、无人机等小型精密驱动”

## P0 拓客优先级

### P0-1：空心杯电机 / 人形机器人微驱动链

原因：

- 痛点明确：微型电机寿命、磨损、噪声、能耗。
- 客户对新材料和表面处理接受度较高。
- 容易讲清楚超滑价值。

优先客户：

- 空心杯电机企业
- 灵巧手企业
- 伺服执行器/微驱动企业
- 医疗器械、无人机、航天航空微驱动客户

### P0-2：MEMS 射频开关 / 高频器件链

原因：

- 官网已明确 MEMS 射频开关应用方向。
- 可直接围绕低插损、高隔离度、开关寿命和高频可靠性讲价值。

优先客户：

- 射频前端企业
- MEMS 器件企业
- 基站设备和相控阵雷达供应链
- 高频测试设备/ATE 企业

### P0-3：微动发电机 / 自供电传感器链

原因：

- 官网已明确微动发电机应用方向。
- 可对接物联网传感器、智慧电网、铁路/物流/工厂状态监测。

### P1：精密材料/微纳加工平台链

原因：

- 更容易接受“小样测试、联合验证”。
- 可作为超滑技术的工艺放大伙伴。
- 需要更强实验平台和材料参数支撑。

### P1：6G 系统级客户

原因：

- 系统级价值大，但应用路径比 MEMS 射频开关更间接。
- 更适合在 MEMS 高频器件验证后再拓展。

## 风险提示

1. 清力技术有限公司主体未核验，不能作为对外材料。
2. 官网已确认 MEMS 射频开关、微动发电机、空心杯有刷电机、实验平台方向；具体性能指标仍需官方测试资料确认。
3. 超滑项目如果没有测试数据，拓客话术必须定位为“共同验证”，不能承诺性能提升。
4. 6G 系统级客户需要谨慎，优先从 MEMS 射频开关器件链切入。
