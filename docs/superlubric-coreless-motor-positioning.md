# 自超滑空心杯电机销售定位与社会价值框架

更新时间：2026-07-13

## 产品主线

当前产品、销售推荐、宣传内容和首批 RAG 知识库统一聚焦：

```text
自超滑空心杯有刷电机
```

目标不是把“超滑”包装成泛材料概念，而是围绕微型精密驱动中的可验证问题建立价值主张：

- 电刷/换向器磨损
- 使用寿命
- 高频动作下的稳定性
- 噪声与发热
- 维护和替换频率
- 精密控制与小型化

## 销售价值链

```text
技术改进
-> 部件级表现
-> 设备级结果
-> 客户运营价值
-> 社会效益
```

### 技术改进与证据边界

待产品资料和测试数据确认的候选能力包括降低摩擦和磨损、改善微接触界面稳定性、改善电刷/换向器寿命、降低由摩擦带来的热和噪声。

以上都属于待验证结论；在没有测试报告前，不能作为对外承诺。

### 部件级表现

产品文档应至少提供：

- 工作寿命 / 循环次数
- 摩擦系数或磨损率
- 温升
- 噪声
- 能耗 / 效率
- 一致性和失效模式

### 设备级与运营价值

只有部件级数据成立后，才可进一步推导微驱动维护间隔、换件频率、计划外停机风险和设备使用阶段能耗的变化。

## 能耗降低意味着什么

能耗降低不是一个可以脱离边界直接宣称的卖点，应被拆成四层：

```text
相同任务、相同负载、相同工况
-> 实测输入功率或能量下降
-> 单台设备年耗电下降
-> 按使用数量和电力排放因子估算环境影响
```

| 影响方向 | 可能机制 | 必须具备的证据 |
| --- | --- | --- |
| 节能 | 相同工况下系统输入能量下降 | 效率/功耗对比、负载曲线、测试方法 |
| 减排 | 可审计节电量乘以适用电力排放因子 | 节电量、地区排放因子、计算边界 |
| 减少材料消耗 | 寿命延长可能减少备件和替换频率 | 寿命数据、替换件数量、材料质量 |
| 减少电子废弃物 | 模块报废和更换减少 | 维修记录、报废率、回收路径 |
| 提升设备可用性 | 更少停机和维护可能提升设备利用率 | 现场运行数据、停机记录 |

没有完整数据时，销售 Agent 应使用以下表述：

> 我们希望通过降低微驱动中的摩擦与磨损，探索设备寿命、维护频率和能效方面的改善。具体节能和寿命收益需要结合您的负载、工作周期和测试条件共同验证。

禁止使用“必然降低 X% 能耗”“必然减少 X% 碳排放”“必然延长 X 倍寿命”等无证据表述。

## Review 规则

必须人工审核：

- 性能数字、百分比、倍数
- 节能、碳减排、环保效益
- 客户案例、合作关系和公司事实
- 医疗、航空航天、机器人安全相关陈述
- 与竞品的直接性能比较

可自动生成但必须显示证据缺口：

- 场景问诊问题
- 产品适配假设
- 样品测试建议
- 维护成本和能耗的计算框架
- 电话、微信、邮件的初稿

## 首批话术主题

1. 灵巧手高频动作下的电刷/换向器寿命问诊。
2. 医疗器械微驱动的噪声、温升与维护间隔问诊。
3. 无人机和精密执行器的轻量化、可靠性和换件频率问诊。
4. 样品测试 / 联合验证邀请。
5. 能耗与维护成本的共同测算提案。

## 产品资料上传后的建库要求

每份产品文档进入知识库前，需要提取：

```text
产品型号
应用场景
额定参数
工作条件
寿命/循环测试
能耗或效率测试
噪声/温升测试
失效边界
测试方法
来源页码
可公开等级
```

以上信息不完整时，Agent 必须显示“证据不足”，并优先生成问诊或样品验证话术。
